# CalTool Releases

Published installers for **CalTool**, Altech Electronics' ECU calibration and measurement
application for Windows.

## Download

Get the latest installer from the
[Releases page](https://github.com/AltechElectronics/CalTool-Releases/releases/latest):
download `CalTool-Setup-<version>.exe` and run it.

CalTool checks this repository for new releases on its own, and offers to download and install a
newer build when one is published.

## Requirements

64-bit Windows. The installer is self-contained - it carries its own .NET runtime, so nothing
needs to be installed alongside it.

## About this repository

This repository holds released binaries only; it contains no source code. CalTool's source lives
in a separate, private repository. The split is deliberate: it means a shipped copy of CalTool
never has to carry a credential in order to check for updates.
